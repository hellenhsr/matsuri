# Passos para rodar
1. Baixar repositório do GITHUB
2. Abrir no VSCode
3. No terminal (Ctrl + J) escrever:
```
npm i
```
4. Esperar instalar
5. Ligar o Wamp
6. Rodar o script SQL banco.sql
7. Voltar no terminal e rodar:
```
node js/server.js
```
8. Abrir o index.html no live server
9. Testar
10. Qualquer coisa fala com lelena
